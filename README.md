# Gentles - Premium Car Website

## Introduction

Gentles is a simple car sales website developed as a group project for Web Development.

The website is designed for selling premium and sport cars with a modern, luxury-style interface. The design was inspired by popular high-end car brands such as Mercedes-Benz, BMW, Lamborghini, and other premium automotive companies.

The main goal of this project was to practice web development skills by creating a functional and visually appealing car marketplace website.

---

## Project Purpose

The purpose of this project was to build a premium-looking car sales website with basic e-commerce functionality.

The website allows users to browse available cars, create an account, log in, and add or remove cars from the shopping cart.

This project helped us practice front-end development, user interface design, local data handling, and basic website deployment.

---

## Main Features

1. View Available Cars
Users can browse the list of available premium and sport cars displayed on the website.
Each car is presented with relevant information and a premium visual style.

2. Login and Register
The website includes basic login and registration functionality.
Users can create an account and log in to access the website features.

3. Add Cars to Cart
Users can add selected cars to their cart.
This simulates a basic online shopping experience.

4. Remove Cars from Cart
Users can remove cars from the cart if they change their mind.

---

## Data Storage

This project uses localStorage to save user and cart data.

This means the data is stored only in the user’s browser temporarily.

The website does not use a real backend server or database. Because of this, the saved information is not permanent and may be cleared if the browser data is deleted.

## Website Functionality

The website includes the following functionality:
- View available premium and sport cars
- Register a new user account
- Log in to an existing account
- Add cars to cart
- Remove cars from cart
- Store temporary data using localStorage

## Example Use Case

A user visits the Gentles website and browses the available premium cars.

After finding a car they like, the user can register or log in, add the car to their cart, and manage the cart by adding or removing cars.

Although the website does not process real payments or save data in a real database, it demonstrates the basic structure of an online car marketplace.
